# StoryMotion 下一次更新概要

更新时间：2026-07-23

建议版本主题：万相视觉资产、多角色一致性与关键道具锁定

## 更新目标

本轮更新集中解决 AI 漫剧制作中的三个核心问题：

1. 图片模型供应商与文本、视频模型解耦；
2. 角色在不同场景和分镜中的脸、发型、服装、画风与表情不稳定；
3. 手机等剧情关键道具前后外观变化，以及连续参考造成的雪花噪声。

## 模型分工

- MiniMax：小说、剧本和分镜文本生成；
- 阿里云百炼万相 `wan2.7-image-pro`：角色、道具、场景和分镜关键帧生成；
- MiniMax 海螺：视频生成，保持原有接入，本轮测试未调用视频接口；
- 未配置万相时，MiniMax 图片接口仍可作为回退。

## 主要功能

### 1. 万相图片供应商

- 新增正式的 `WanImageProvider` 与 HTTP 传输实现；
- 支持万相多参考图输入，最多传递 9 张参考资产；
- 支持常用纵横比与固定尺寸；
- 只允许官方 DashScope API 主机和阿里云 DashScope OSS 结果地址；
- 图片下载采用大小、格式和重定向校验，并原子写入本地文件；
- 前端在配置 `DASHSCOPE_API_KEY` 后自动优先使用万相。

### 2. 角色身份、风格和表情约束

- 每个角色先生成白底正面身份锚点图；
- 再根据身份锚点生成白底多角度角色建模图；
- 场景与关键帧同时引用出镜角色的身份图和建模图；
- 提示词拆分为身份、表演、构图和审美四类契约；
- 锁定脸型、五官、发型、年龄、体型、服装层级和标志性特征；
- 表情指令细化到眉毛、眼睑、视线、瞳孔、嘴部、下颌、头部角度、肩膀和身体张力；
- 统一为精致二维国漫、赛璐璐上色和电影化色彩脚本。

### 3. 多角色镜头

- 万相镜头可同时接收多个角色的建模图；
- 不再局限于 MiniMax 单主体参考；
- 双人或多人画面会按角色顺序传入独立身份资产，减少串脸、换装和角色合并。

### 4. 关键道具一致性

- 协议层新增 `StoryProp`、场景 `prop_ids` 和镜头 `prop_ids`；
- MiniMax 需要在剧本中声明重复出现或承担剧情信息的道具；
- 本地增加手机、信件、照片、钥匙、证件、刀、枪、药瓶、项链、戒指、手表和雨伞等保底识别；
- 每件道具生成独立的白底多视角标准图；
- 手机可锁定机身颜色、保护壳、摄像头布局、边框和磨损位置；
- 相关场景和分镜共同引用同一道具标准图；
- 普通桌椅不会自动生成，避免无意义消耗图片额度。

### 5. 雪花噪声修复

旧流程会把上一张关键帧继续作为下一张的参考。万相会逐次放大上一张图里的微小纹理误差，最终形成彩色雪花。

新流程：

- 不再把任何生成关键帧作为后续关键帧输入；
- 每个镜头只从干净的角色、道具和场景标准资产独立生成；
- 每个镜头使用基于 `shot_id` 的独立 seed；
- 用镜头契约保持叙事连续性，不做像素级链式复制。

### 6. 文本 JSON 稳定性

- 支持 MiniMax 返回单元素根数组；
- 支持 `result`、`data`、`output` 等常见响应包装；
- 多个候选对象会明确拒绝，不会静默猜测；
- 重试提示明确要求根节点为单个 `{story, screenplay}` 对象；
- 错误信息从 Python 类型异常升级为可定位的协议错误。

### 7. 前端视觉资产展示

“视觉资产”页现在可以直接展示：

- 角色身份图和多角度建模图；
- 关键道具标准图；
- 场景参考图；
- 所有分镜关键帧；
- 当前视觉资产版本和旧版重建提示。

旧版资产不会被自动覆盖。用户确认图片额度后，可按新版流程重建。

## 配置

`.env` 需要：

```dotenv
MINIMAX_API_KEY=
MINIMAX_TEXT_MODEL=MiniMax-M2.7

DASHSCOPE_API_KEY=
DASHSCOPE_API_HOST=https://dashscope.aliyuncs.com
DASHSCOPE_WORKSPACE_ID=
DASHSCOPE_IMAGE_MODEL=wan2.7-image-pro

MINIMAX_VIDEO_API_KEY=
```

真实 `.env` 已被 Git 忽略，只提交空值模板。

- 完整自动化测试：171 项通过；
- Streamlit 健康检查：HTTP 200 / `ok`；
- 前端完整加载未发现致命运行异常；

## 升级与测试说明

1. 拉取更新并保留本地 `.env`；
2. 重新生成小说、剧本和分镜，使新剧本包含关键道具协议；
3. 在“视觉资产”页确认万相图片额度；
4. 使用新版流程重新生成视觉资产；
5. 旧图片目录保留，不会被自动删除。

## 已知限制

- 万相属于付费服务；账号欠费时会返回 `Arrearage`，需在阿里云“费用与成本”结清后重试；
- 新流程会为每件关键道具额外生成一张标准图；
- 万相多参考仍受最多 9 张输入限制，极端多人、多道具镜头会按角色、场景、道具优先级截取；
- 本轮最后一次视觉回归因阿里云账号欠费未重新计费生成，但代码路径和 171 项自动化测试均已通过；
- 当前改动不包含最终视频效果验收。
